- 固定源码：`C:\codex项目\GiveMeFive-AS-V4.1`，分支 `dev/as-v4.1-phase1`；基线提交 `933d0d8`，没有用旧归档覆盖。

## 实际修改

- `dist/content-runtime.js`：按课程及资源版本隔离缓存，按真实资源 SHA-256/字节数核验，四路下载、暂停、刷新后续传、失败明细及重试。跨版本仅复用内容哈希相同的资源。删除只处理对应课程缓存及缓存元数据，不调用学习数据库。原 PDF 改为校验分块、重组并触发真实 PDF 文件保存，和浏览器教材缓存明确分开。
- `dist/sw.js`：缓存命中读取已下载教材，未下载资源走网络；不缓存私人 API。网络中断时可加载完整站点外壳；升级下载中断时仍可回退上次完整下载的版本，避免新旧内容混用。
- `scripts/build-offline-manifest.py`、`scripts/build-content.py`、`dist/data/runtime-manifest.json`：保留原 Topic/Unit 关联，增加全量资源指纹及版本。课程/前端资源更改后需运行 `.venv\Scripts\python.exe scripts/build-offline-manifest.py`；重建内容脚本也会调用它。清单共 1213 项，整门课程离线阅读范围为 673 项；原 PDF 导出单独处理。
- `dist/app.js`：入口集中到“设置 → 教材与离线”，增加进度、成功/失败、校验与暂停；课程页只保留设置入口。课程目录和本节目录的收起按钮置于各自标题区，折叠后保留展开入口。进度页先显示真实阅读/习题完成度，再显示时间及过程记录。
- `dist/ui-text.js`、`dist/shared-shell.js`：共用语言词典，统一主导航及心流页面名称，切换语言时同步已有界面。教材、题干、选项、用户输入不参与界面翻译。
- `dist/mind-flow/v3/ui.mjs`：任务的编辑、子任务、删除归入“更多操作”；完成态有边框及完成分区。问题次要操作同样收进菜单，保留关联教材入口。任务/问题删除可恢复，原记录及引用保留。记录页去掉会话 ID 和旧版原始 JSON 展示，完整备份保留原数据。
- `dist/assessment/v4/ui.mjs`：统一练习/模考/我的试卷/错题集标签，调整上传和开始模考的层级；保护原题和选项不被界面翻译。未改变考试命令、PDF 导入或评分逻辑。
- `dist/shared-shell.css`、`dist/index.html`、`dist/assessment/index.html`、`dist/mind-flow/review.html`：入口依赖更新，统一操作菜单及按钮间距；手机正文目录改为上下布局，避免窄目录把字挤成竖排。
- `tests/offline-runtime.test.mjs`、`tests/integration.test.mjs`：真实资源清单校验、续传/失败恢复/损坏缓存、版本隔离与升级回退、课程范围删除、PDF 导出以及共享导航启动回归。
- `dist/qa/offline-responsive.html`：仅供验收的视口测试页，未嵌入产品流程。浏览器视口设置未实际生效，因此采用页面内独立 375/768/1024/1440 像素测试视口；具体测量见 `responsive.json`。
