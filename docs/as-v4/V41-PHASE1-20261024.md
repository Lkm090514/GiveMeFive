## 启动和继续开发

Windows 双击根目录 `Start-GiveMeFive.cmd`，打开本机管理员入口。默认网站 `http://localhost:4173/`，Assessment 在 `/assessment/`。也可在项目根目录执行 `.venv\Scripts\python.exe -X utf8 scripts/run-v4.py --open`。

正式本地数据放在 `runtime/v4`；真实 PDF 验证数据单独放在 `runtime/qa-v41-workbook-final`。不要将测试库替换成正式库，也不要删除旧工作区。本轮没有推送、部署、线上同步或生成大型 ZIP。

剩余：扫描 PDF OCR 依赖与人工复核、DOCX 外部转换依赖、更多真实版式逐题视觉审核、具有可靠原答案表的真实 PDF 验收、浏览器实际点击流程及 iPad Safari 尚未在本轮完成。下一轮优先扩大真实版式视觉核对，并补齐前端实际操作验收。
