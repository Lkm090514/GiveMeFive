# 本轮桌面浏览器联调

日期 2026-10-23。工具控制的真实 Chromium，内网同源 Fusion + Python 服务。不是静态演示，不是 iPad Safari。隔离 QA 身份，数据为自编试卷。正式运行数据未用于测试。

| 操作 | 实际结果 |
|---|---|
| Topic 2.5 创建 1 题 Practice | 真实题库生成，服务端固定版本与顺序 |
| 选 A、检查 | 错误，显示可靠 B，收录错题；原作答保留 |
| 填写原因、思路和笔记，准备检查 | 保存修正版本及题目版本，显示等待独立检查 |
| 1 题 Independent Check | 取另一道未见公共题，活动中不显示逐题检查答案 |
| 选 B、整组提交 | 正确，安排次日延迟复查；Results 显示本次 Topic 数据不足 |
| 从结果查 PL 2.5 | 打开真实教材；“返回 AS 原会话”恢复同一结果会话 |
| 打开现有 Progress | 显示长期 Topic 首次/重做/未知独立性/未评估，未产生掌握分 |
| 标记复查正确题为猜对 | 单独 Bookmark，错误次数仍为 0；原成绩保留，来源错题恢复等待独立检查 |
| 学生上传 7 页自编 PDF | 自动拆出 6 道 MCQ，保存 7/7 页段；6 道答案均匹配可靠来源；没有学生答案编辑器 |
| 先启动 MF，再正式开始私人模考 | AS 独立 2 分钟倒计时；正式页面无 MF、答案、解析或教材按钮 |
| 选第 1 题 A，导航第 3 题并刷新 | 题号和答案恢复，截止时间不重置 |
| 新开标签进入 Practice / MF | Practice 跳回活动考试；MF 显示考试锁和已暂停，无法继续计时 |
| 等待真实截止时间 | 自动提交，1 错、5 未答、0 未评分；结果可回看 |
| 考试后另一 MF 标签刷新 | 仍为已暂停，恢复按钮需手动点击，没有自动恢复 |

本轮发现并修复了前端创建会话时的路由竞态：hash 改变可能发生在 busy 操作期间，导致 URL 已进入 Session 而界面仍停留在表单。现在立即显示已创建会话，并在操作完成后处理待执行路由。后续浏览器创建独立检查及私人模考已验证。
