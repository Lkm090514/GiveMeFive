## 最终产品口径

以用户最后两次澄清为准：

- 管理员持续批量上传多份 PDF/DOCX，拆解成公共题库 MCQ，保留来源、题号、图片/公式、题目版本、答案来源及 PL Topic。
- 学生可以从公共题库自由练习，也可以上传自己的 PDF，由平台自动拆成可作答的试卷，选择自由练习或正式模考。学生上传是 owner-private 范围，不加入公共题库。
- 不让学生填写或决定标准答案。原卷明确答案与已核对题库同题匹配优先；可配置 V3 服务端模型尝试独立求解。无可靠答案时仅保存学生选项并显示未评分，模型候选不因自报置信度被当成确定答案。
- 错题记录知识点与解题类型，再查询管理员公共题库中的相关 MCQ，支持持续新建练习。保留每次错误、重做和题目/答案版本；再次答对不自动移出。
- 学生主导航仍为 Practice / Exam / Mistakes；上传和自己的试卷是 Exam 内部流程。没有把“自己创建试卷”改成从公共题库组卷。

## 已实现

1. 同一 Fusion：保留原导航、共享明暗主题、7 Units/41 Topics、全部教材/图像/课程 bundle、在线/离线机制和 MF Stage A 核心。新增 PL Topic“练习本知识点”和返回原 AS 会话。
2. V3 复用：同一 SQLite 内的 Question/QuestionVersion/AnswerKey/Asset/ImportQueue 继续作为题库。V4 只加会话、作答、错题、试卷集合、Topic 元数据、评分修订和幂等键等表，没有第二套题库。
3. 管理员导入：每批 1–20 文件；持久队列、进度、失败原因、重试、重新解析、原文件保留、请求幂等；DOCX 转成保真 PDF 后复用同一解析核心。自动摘要和结构异常阻止静默发布，可一键发布结构合格题。无答案可保留未评分状态。
4. 原题呈现：共享题干/图像引用、坐标/页码、结构化文本、原始裁剪图。显示裁剪只收紧底部空白，同时保留原范围中的所有文字、图片与矢量内容；原始资产不覆盖。复杂公式/图像使用原图，未引入不必要的公式重排框架。
5. Practice：课程/Unit/多 Topic、数量、随机/顺序、综合题；服务器固定题目版本和顺序；选择后主动检查，检查后锁定；重试追加记录；退出、刷新、查 PL 返回后恢复。
6. Exam：管理员原始 MCQ 试卷或学生 PDF 试卷；配置名称/年份/课程/数量/时长/MCQ 类型/版本；服务端持久化截止时间、后台到时结算、答题和交卷同一事务检查时限、刷新/关闭恢复、幂等提交、提交后不可改答案。正在考试时 API 不返回答案/解析，并屏蔽其他会话回看和错题接口。
7. Mistakes：练习答错时立即收录；考试收录错误与未答；无可靠答案不归错；按身份+稳定 Question ID 一个当前条目，多次历史记录；筛选、原题、历史、重做、解析、PL 链接、相关练习、手动移出。
8. 相关推荐：只查询已发布公共 MCQ，使用现有 PL canonical Topic 和可用的解题类型，默认排除原题；对学生上传的原题，也排除公共题库里可确认的同一原题副本。每轮 ID 不重复、可靠答案优先、题量不足返回实际数量。没有扩展相似内容自动合并/去重。
9. MF：AS 自由练习和 PL 使用同一会话；显式页面跳转可移交计时。正式考试开始先原子暂停/保存锁，所有标签页共同读锁；正式答题页面隐藏 MF 及提醒；交卷后不自动恢复。断网/接口不可用时不凭空解除持久锁。
10. 数据：V3 原题/答案不可变版本、学生作答不可变、重评分追加 Grading Revision；旧 Learning Ledger 不删除。AS 结果投递现有 Ledger 时稳定 event_id 去重，只有可确认的真实归属才写 course/unit/topic。
11. 权限：管理员导入/改答案/标签/发布由后端角色校验。学生上传只能创建自己的试卷；公共题库、私人原题和学生记录按 scope/owner 隔离。不能靠隐藏按钮代替权限。

## 本次承接开发：连续专项练习

本次在上次集成版本 e368115 上继续修改源码，沿用学生上传 PDF 自动拆卷的产品方向。

- 从私人试卷题目或错题进入相关练习后，服务端保存原题版本、Course/Topic、解题方法和类型、是否扩大范围，以及本轮已安排的题目 ID。
- 完成结果页新增“继续下一组”。后续分组保持初始专项范围，不随新题或后来修改的原题标签改变目标；默认排除本轮已练题和原题的可确认同题副本。
- 公共题库新增匹配题会进入后续查询。数量不足返回实际数量；耗尽时明确提示，不自动重复。学生可主动选择“允许重做本轮已练过的同类题”，开始新一轮。
- 练习范围由服务器从本人已完成会话读取，前端不能用任意题目列表覆盖；其他用户不能接续；正式考试期间仍禁止开启专项练习。
- 类型尚未确认时，页面允许先按已确认 Topic 练习，不强制选择未知类型。
- 修复弹窗错误提示被背景遮挡的问题。
- 数据沿用现有 SQLite JSON 会话载荷，无新增账号系统、数据库或破坏性迁移。旧会话继续读取；仅新建的相关练习具有连续分组信息。

## 2026-10-23 承接：管理员公共题库与双维标签

- 新增真实公共题库概览与全部 41 Topic 的覆盖表；只统计公共题，学生私人上传排除在外。覆盖表只计已发布题的核心 Topic，多 Topic 分别计入各 Topic；另列可靠答案数量，不将覆盖解释为学生掌握程度。
- 管理员可以核对多个解题方法和题目模型，也可明确保留未分类。复用现有 V3/V4 类型 ID，不另建 PL Topic。必须填写核对依据，追加不可变修订记录；题目版本和分类版本同时校验，阻止陈旧覆盖。修复自动规则压过人工标签的问题。

- 新建 Session 固定题型快照；之后管理员修改类型，不改变该 Session 和原始作答记录中的题型。原有记录不删除，不强行补写未经记录的历史标签。

- **生产身份与云端部署未完成。** 当前是可运行的真实本地 Python + Fusion 集成。默认本机访问沿用 V3 Principal/token 契约；生产 ChatGPT 身份代理、角色来源、TLS 和 Python 托管未验证。原静态 HTTPS 网站不能执行 Python，本轮没有用静态壳冒充完整 HTTPS V4。
