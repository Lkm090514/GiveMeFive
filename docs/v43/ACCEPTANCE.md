## 数据库、文件与认证边界

新增幂等迁移 `backend/migrations/006_online_identity.sql`：`v43_users`、`v43_logins`、`v43_invites`、`v43_login_limits`、`v43_paper_reviews`，不重建已有题库、会话或学习数据。

生产镜像以非 root 用户运行，持久目录为 `/var/data/gmf`。SQLite、身份、作答、导入队列及原文件/题图都必须保存在该目录。启动要求明确确认持久磁盘；单实例、一个 Uvicorn worker，继续使用已有解析队列与考试状态机。

生产要求 HTTPS 前端 Origin、服务器网关密钥以及 password 模式。浏览器只有自己的 Secure/HttpOnly/SameSite Cookie；服务密钥不进入前端。代理剥离 Sites Cookie/平台身份凭据，只转发 GMF 会话；变更请求校验 Origin 和专用请求头。生产后端不提供教材静态文件。`/health` 用于基础诊断，`/ready` 同时检查数据库、解析线程及 LibreOffice。

没有在正式环境创建共享管理员或 QA 学生。初始管理员由私有主机 CLI 生成一次性邀请，学生各自注册。管理员邀请码 CLI 与学生邀请码 API 已实现，尚未配置邮件投递、密码找回、正式用户运营界面。

## 浏览器实际操作

使用桌面 Chrome 连接隔离环境中的真实 FastAPI，没有模拟 API。实际完成：GMF 首页 → AS 未登录提示 → 独立 QA 学生 A → 空公共题库 → 上传 `v4-no-key.pdf` → 等待后台解析 → 原题图对照并逐题确认 → 正式考试 → 选择测试选项 A → 刷新保留作答 → 提交 → 查看“未评分”结果。该选项仅用于测试作答保存，不推断正确答案。

随后注销 A，进入独立学生 B，私人试卷列表为空；后端测试另外验证 B 猜测 A 的原文件、题图、会话 URL 均不能取得数据，普通学生不能使用管理员接口。停止并重新启动浏览器验收后端后，以 A 身份再次查看到同一结果与答案。结果截图已单独保留，未上传公开仓库。

浏览器身份进入使用隔离测试专用的两个学生入口，未使用管理员；正常密码注册/登录由真实 HTTP 自动化验证，未宣称已在浏览器手工输入密码验收。测试入口脚本不包含在生产 Docker 镜像中。容器中的 HTTP 回环测试仅用于 CI，明确 `tls_browser_acceptance=false`；不能替代正式 HTTPS Cookie 验收。真实 iPad Safari 尚未测试。
