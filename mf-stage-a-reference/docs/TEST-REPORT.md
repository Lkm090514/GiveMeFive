## 额外可靠性检查

- wall clock 回退、两个时钟差异、长调度间隔：不计可疑段，安全暂停。
- 非 owner 心跳不累计；外部显式暂停不补算未知时间。
- 结束后时间冻结、旧 Session 控件拒绝覆盖新 Session、会话 ID 重用拒绝。
- 模拟持久写入失败：状态回滚，不报告成功；后续大间隔不补时。
- 序列化损坏 anchor、phase、notice 或未知 schema：拒绝读取为正常会话。
- 随机测试以独立累计模型比较 1500 步转换，验证休息/专注与任务分配守恒。
